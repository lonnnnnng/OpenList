## 1. 交付顺序

**固定构建与骨架 → 夸克生成/播放闭环 → 安全增量和回收 → 阿里/百度/UC → 双媒体服务器与完整UI → 容器和长期验收 → 扩展网盘与302。**

不同时开工四盘和复杂播放反代。每一阶段必须有可执行的演示和停止条件；四盘中任一账号/授权模式无法验收时，单独记录为阻塞项，不能将“驱动存在”记作盘已支持。

一期总计约 **21～31人天**，是研发工作量区间，不是日历发布日期或质量承诺。API变动、账号授权申请、TV/Infuse设备不可用及等待用户验收的时间另计。M0～M2约8～11人天交付可看的夸克原型；M3之后才应开启长期删除同步。

不沿用原文“9～12人天完成四盘＋多客户端稳定产品”的承诺。单个熟悉Go与SolidJS的实施者串行推进时，实际日历还包含审核、账号和设备准备；有独立探索协作也不能省略主实现者对关键代码与最终验收的负责。

## 4. 每阶段必须可演示的场景

### M0

首次启动出现本地管理界面，版本页面显示产品/上游/前端SHA；指定数据卷持久化，重启后保留配置；构建不触碰用户旧前端/标签/生产数据库。

### M1

创建夸克任务草稿，选已知目录和独占输出；预览新增项及冲突。模拟目录读取错误后，结果标为不完整，删除栏明确显示禁止执行。

### M2

本机/amd64容器 smoke 先用Local夹具生成一条STRM，验证未登录签名播放、GET/HEAD/Range、错误签名拒绝和重复运行不重写未变文件。真实退出条件仍是在明确的夸克测试目录生成电影和剧集，由Jellyfin读取播放并完成seek，同时记录实际取流方与中间件流量；真实验收前不标记M2完成。

### M3

模拟一次扫描失败不清理；在真实测试目录中由用户确认删除测试文件后，连续两次完整扫描才回收本地产物；恢复无覆盖；任务运行中取消与容器异常退出均能对账。

### M4

四盘同一套任务/API/UI分别运行；账号Key/Token过期时只阻塞相关任务，不误报文件已删除。阿里代理取流的RangeReader、百度UA、UC OnlyProxy按各自模式展示。

### M5

同一个任务绑定两个媒体服务器/库，生成后分别刷新；一台不可达时另一台正常，失败刷新单独重试。家人不需登录中间件，仍在媒体客户端看片。

### M6

候选镜像非root运行、连续任务不出现异常永久删除；备份到新数据目录后恢复，相同STRM入口仍有效；升级出现问题能按数据库版本恢复，不能只换旧镜像。

## 5. 二期路线

| 阶段 | 内容 | 前置门槛 | 验收结果 |
| --- | --- | --- | --- |
| P2-A 扩展网盘 | 115/Open、天翼、迅雷；相同任务与代理契约 | 一期四盘可靠同步稳定，真实扩展账号准备好 | 按认证模式记录读取/生成/播放/seek、外部授权与会员约束 |
| P2-B 文件级直连 | proxy/redirect/auto能力矩阵、QuarkTV/UCTV候选、UA/IP/Header/cache区分 | 原画/转码区别明确，目标客户端直取能力已测 | 最终URL/取流端/带宽路径实证；不支持时可配置代理 |
| P2-C 媒体服务器反代 | 同进程新增监听端口、路径映射、播放请求适配、字幕/状态/转码回退 | 原生客户端选路不能满足目标，且具体Emby/Jellyfin版本冻结 | 媒体服务器/客户端组合验收通过，不强制关闭必要转码 |
| P2-D 可选增强 | 公网HTTPS、凭据字段加密、Webhook、更多协议/网盘 | 分别提交设计并审核 | 只在明确需求下开展，不追加到首发范围 |

二期不承诺固定人天，先按一期实测的网盘与客户端能力重估。第三方受限许可源码不能直接成为本项目免费开源模块；原则上自建适配，参考允许复用的源码时登记来源和许可。

## 6. 首发验收矩阵模板

| 维度 | 必填记录 |
| --- | --- |
| 软件 | 产品SHA/镜像digest、上游SHA、前端SHA、Go版本、依赖/构建平台 |
| 网盘 | 驱动与认证模式、匿名账号标识、会员情况、地区/出口；凭据不入报告 |
| 文件 | 视频/音频编码、容器、字幕、大小/码率、源目录类型；是否云端转码地址 |
| 媒体服务器 | Emby/Jellyfin版本、库类型、挂载路径、探测/转码配置 |
| 客户端 | Web浏览器/Android TV/Infuse版本、设备和网络 |
| 流行为 | 取流端、200/206/416、HEAD、3次seek、续播、链接过期恢复、取消 |
| 同步行为 | 首次生成/第二次幂等、目录异常、两轮缺失、回收恢复、未知文件保留 |
| 运维 | 内存峰值/带宽、关停时间、重启恢复、备份/升级/回滚结果 |

真实账号没测的行保持“未验证”，不能填“支持”或“通过”。原型通过不能替代首发矩阵。
